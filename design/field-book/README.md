# Field Book & Rack handoff

1. Unzip this into the root of the Topout repository. It only adds files:
   `design/field-book/`, `assets/fonts/` (new fonts and licences) and `lib/game/field_book.dart`.
2. Optional: export each artboard from the design canvas as PNG
   and put them in `design/field-book/screens/`.
3. In Claude Code, from the repository root, say:

   > Read design/field-book/HANDOFF.md and do phase 1. Stop after it and show me the screenshots.

Then ask for the next phase each time.
